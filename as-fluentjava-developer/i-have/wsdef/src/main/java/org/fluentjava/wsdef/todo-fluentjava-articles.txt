Syntax colouring exists for a reason. When a programmer reads code, he is <i>parsing</i> it. The parsing
is easier, if the computer has already marked token types with colour.

Like with any tool, you benefit only as much as you actually <i>use</i> the tool. So, in the spirit of Extreme
Programming, why not use the tool as much as possible? Because syntax colouring can even help spot bugs, as
we can see below.
